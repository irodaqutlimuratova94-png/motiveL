# Admitly — University Application Copilot

A static website prototype for motivation-letter feedback, university exploration, and student CV building.

## Run locally

1. Download and extract the ZIP file.
2. Open `index.html` in a modern web browser.

No build tools or dependencies are required.

## Current demo limitations

- Motivation-letter fit scoring uses a simple local checklist, not an AI model or official admissions criteria.
- University profiles are starter notes. Verify current research, program details, and requirements on official university websites.
- Sign-in and sign-up are interface demos only; no real accounts are created.
- The CV builder previews and copies text in the browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `admitly`.
2. Upload `index.html` and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, GitHub will show the public website URL in the Pages section.
